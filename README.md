# APEY

APEY is a mobile API usage tracker built to monitor and keep track of your AI API usage in one place. It provides a simple dashboard for checking usage, limits, and API-related information without digging through different provider dashboards.

**Status:** In Development

## Features

* Monitor AI API usage
* Track API limits and quotas
* View usage statistics
* Support for multiple API providers
* Simple and minimal mobile interface
* Dark-themed mobile interface
* Local/offline data storage
* Quick access to API usage information

## API Providers

APEY is designed to work with AI API providers and keep their usage information organized in one place.

Currently supported providers:

* **Google Gemini**
* **OpenRouter**

API keys and provider information are handled locally within the app.

## Tech Stack

* TypeScript
* React Native
* Expo
* Expo Go
* SQLite

## Setup

```bash
git clone <your-repository-url>
cd src
npm install
npx expo start
```

Open the project with **Expo Go** on your phone.

## Project Status

APEY is currently **in development**. Features, supported providers, and the user interface may change as development continues.
